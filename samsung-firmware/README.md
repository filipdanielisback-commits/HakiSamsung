# Samsung firmware research policy

This directory is for documentation and metadata only.

## Allowed contents

- Links to official Samsung documentation and update notices.
- Firmware version/build identifiers where lawfully and publicly documented.
- Text descriptions of partition roles from legitimate public references.
- A metadata manifest that does not contain firmware payloads.
- Notes about licensing and redistribution restrictions.

## Do not commit

- Samsung firmware archives or extracted proprietary partition images.
- Proprietary Samsung applications, libraries or vendor binaries.
- Private signing keys, certificates, credentials or tokens.
- Files obtained from sources whose redistribution terms are unclear.

## Why

Samsung One UI and associated components are proprietary. Public availability of a file does not automatically grant permission to redistribute or modify it. Use official sources, follow their terms, and obtain permission when necessary.

## Suggested metadata fields

- Product/model identifier
- Region/CSC, if publicly documented
- Build identifier
- Android version
- Security patch level
- Official source URL
- Date checked
- Notes on license and redistribution status
