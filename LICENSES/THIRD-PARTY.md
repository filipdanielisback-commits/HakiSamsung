# Third-party licensing register

This file records third-party materials referenced or later incorporated by the project.

## Current status

- No third-party source code or binary assets are intentionally bundled by the initial documentation commit.
- Samsung One UI, Samsung applications and Samsung firmware are proprietary products. This project does not claim rights to them.
- Android Open Source Project components have their own applicable licenses; review each component's license before reuse.

## When adding material

For every third-party component, record:
- Name and upstream project
- Exact version or commit
- Source URL
- License identifier and license text location
- Local modifications, if any
- Required copyright and attribution notices

Do not assume that a public download can be redistributed. When rights are unclear, link to the upstream source instead of copying the material.
