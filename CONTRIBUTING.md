# Contributing to HakiSamsung

Thanks for helping with research.

## Good contributions

- Correcting a factual error with a reliable source.
- Adding verified device specifications for an exact model.
- Documenting Android or One UI architecture with citations.
- Reviewing compatibility assumptions.
- Improving project documentation and issue templates.

## Before submitting

- Search for an existing report or issue.
- State the exact device model and software version.
- Separate verified facts from assumptions.
- Include primary-source links and the date checked.
- Remove personal data from logs and screenshots.
- Confirm that any submitted code or text may legally be shared.

## Not accepted

- Samsung proprietary firmware or extracted proprietary binaries.
- Private keys, credentials, account data or personal identifiers.
- Claims of successful boot without reproducible evidence.
- Unreviewed flashable packages or instructions presented as safe for everyday devices.

## Pull request checklist

- [ ] The change has a clear research purpose.
- [ ] Technical claims have sources.
- [ ] Unknowns are labelled as unknown.
- [ ] Third-party licenses have been checked.
- [ ] No restricted binaries or personal data are included.
